According to (someone?), "The most advanced linear synths use "Through-Zero FM." If the modulation forces the frequency below 0 Hz, the oscillator doesn't stop; it flips its phase (180°) and runs backward, exactly like a Ring Modulator (DSB-SC) does at the zero line."

** [Claude] answer: our FM can't reach 0 Hz -- but the oscillator core now handles it anyway
The only FM in this codebase is the per-voice vibrato in
=code/rust/midi_pulse/sawwave/voices.rs= (=fm_factor=), shared by all three
synth runtimes (sawwave, looper, surfaces). It is *exponential* FM: the depth
is in *cents*, so the carrier frequency is multiplied by =2^(depth*sin/1200)=,
which is always > 0. No depth can force the frequency below (or even to) 0 Hz,
so through-zero territory is *unreachable* -- it's a property of *linear* FM
(freq = carrier + deviation in Hz), which we don't have.

That said, the oscillator core is now genuinely through-zero-capable:
- the phase accumulator wraps with =rem_euclid=, so a negative increment runs
  the oscillator backward instead of walking the phase out of range -- for a
  sine that is exactly the 180° flip the quote describes (=sin(-x) = -sin(x)=,
  the ring-mod identity at the zero line);
- PolyBLEP band-limiting uses =|dt|=, so square/saw stay band-limited while
  running backward.
Unit tests pin both behaviors. If we ever add *linear* FM (or any modulator
that can push frequency negative), through-zero comes for free.

If what you actually want is audible through-zero *linear* FM as a playable
timbre dimension, that's a new timbre parameter + rig surface -- happy to
build it, but since nothing existing would change sound, I stopped here.
(Also noted in jeff-maybe-review-this.org.)

** [Claude] done -- exponential pluck decay to a sustain plateau, all synth rigs
A real pluck rises in a few ms and decays exponentially (the fundamental's
time constant is roughly 0.5..1.5 s on a guitar); I kept the fast linear
attack and added the exponential decay -- but toward a *sustain plateau*
(default 0.35 of the peak, ~-9 dB) rather than to silence, because notes that
die out entirely would make held notes and (especially) accrete drones fall
silent. So: strike = full peak, ringing notes settle at the sustain -- fresh
notes stand out exactly as you asked.

Two new optional =cpal_synth= fields (defaults apply to EVERY synth rig --
sawwave, looper, surfaces -- since you said "the synths"):
- =sustain_level= (default 0.35; >= 1.0 disables, restoring the old flat envelope)
- =decay_secs= (default 0.5; the exponential time constant; <= 0 disables)
Both commented in the surfaces toml and rigs/README.org. Loop playback
notes get the same curve (they go through the same sink); chord-accretion
voices stay flat drones. If the looper rigs shouldn't have changed, set
=sustain_level = 1.0= in their tomls (also flagged in
jeff-maybe-review-this.org).
