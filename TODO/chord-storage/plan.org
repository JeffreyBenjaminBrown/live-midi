#+TITLE: Plan: monome chord storage (v2)
#+DATE: 2026-04-25

* Goal

Generalise the single accretion slot into 15 named chord slots
plus a "silence" button. Each chord has its own pitch set; at most
one chord emits at a time; the *accretion target* (the chord that
=accrete-on= and =wipe= operate on) is a separate piece of state
from the *emitting chord*. A new =set-accretion-target= modal
button reassigns the target. Modal feedback uses /grid/led/level/
varibright (four distinct levels per the README).

=consts.rs=. =types.rs= and =consts.rs= are leaves. Domain modules
generally don't import each other, except where natural (e.g.
=state.rs= uses =leds.rs= and =voices.rs=).

* Types (in =types.rs=)

#+begin_src rust
  // --- existing, unchanged ---
  pub type MonomeKey = (i32, i32);
  pub type EdoPitch = i32;
  pub type Rect     = (MonomeKey, MonomeKey);
  pub type VoiceId  = u64;

  pub struct PitchClass {
    pub key_to_pitch:  HashMap<MonomeKey, EdoPitch>,
    pub key_to_pitchclass:  HashMap<MonomeKey, EdoPitch>,
    pub pitchclass_to_keys: HashMap<EdoPitch, Vec<MonomeKey>>,
  }

  // --- new ---
  pub type ChordId = usize; // 0 = silence, 1..=15 = chords

  // Per-chord accretion slot (was a single global field). First-
  // insertion-wins semantics still apply, per chord.
  pub type Chord = HashMap<EdoPitch, HashSet<VoiceId>>;

  // VoiceSource gains a chord tag on the Accreted variant, so two
  // chords sharing a pitch don't collide in the voices map during
  // emitter transitions.
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
  pub enum VoiceSource {
    Fingered { xy: MonomeKey },
    Accreted { chord: ChordId, pitch: EdoPitch },
  }

  #[derive(Debug, Clone, Copy)]
  pub struct VoiceState {
    pub id:              VoiceId,
    pub freq:            f32,
    pub phase:           f32,
    pub env:             f32,
    pub target_env:      f32,
    pub ramp_per_sample: f32,
  }
  pub type VoiceMap = HashMap<VoiceSource, VoiceState>;

  // The Chord variant gains a chord-id tag because two chords
  // might both contain a pitch class P; when we switch emitters we
  // need to remove the right one's reasons without disturbing the
  // other's.
  #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
  pub enum PitchLedReason {
    PitchEquivalent { source_xy: MonomeKey },
    Chord           { chord: ChordId, pitch: EdoPitch },
  }
  pub type PitchLedReasons = HashMap<MonomeKey, HashSet<PitchLedReason>>;

  // Window types unchanged.
  #[derive(Debug, Clone, Copy, PartialEq, Eq)]
  pub enum WindowId {
    Edo,
    ControlsTop,    // y=14, x=0..3 (was Accretion2x2 / EmitToggle1x1)
    ControlsBottom, // y=15, x=0..15
  }
  pub struct Window { pub id: WindowId, pub rect: Rect }

  // Button kinds unchanged in shape; the action enum (ButtonAction)
  // gains chord-storage entries.
  #[derive(Debug, Clone, Copy)]
  pub enum Button {
    Toggle { state: bool, on: ButtonAction, off: ButtonAction },
    Nursed { state: bool, on: ButtonAction, off: ButtonAction },
    Fire   { fire: ButtonAction },
  }
  #[derive(Debug, Clone, Copy)]
  pub enum ButtonAction {
    AccreteOn, AccreteOff,
    WipeFire,
    EmitIsToggleOn, EmitIsToggleOff,
    SetTargetFire,                    // enter target-select mode
    ChordEmitOn  { chord: ChordId },  // pressed in Toggle mode-on,
                                      //   or any chord press in Nursed
    ChordEmitOff { chord: ChordId },  // pressed in Toggle mode-off,
                                      //   or any chord release in Nursed
  }

  // The five-tuple LED command emitted by handlers, run through
  // the compositor on its way to the device.
  pub type LedCmd = (WindowId, MonomeKey, Brightness);

  // Brightness as an exhaustive enum, no magic numbers at call sites.
  // The four lit levels match the four distinct buckets the device
  // appears to render — see leds::low_res_brightness.
  #[derive(Debug, Clone, Copy, PartialEq, Eq)]
  pub enum Brightness { Off, B0, B1, B2, B3 }

  pub struct AppState {
    pub voices:           Arc<Mutex<VoiceMap>>,

    // Per-chord accretion slot. Indexed by ChordId. Index 0 is
    // silence — its slot is always empty by invariant.
    pub chords:      Vec<Chord>,    // length = N_CHORDS
    pub accretion_target: ChordId,                // never 0 (silence)
    pub emitting_chord:   Option<ChordId>,        // None = nothing emits

    pub emit_is_toggle:   bool,                   // mode for chord buttons
    pub accrete_on:       bool,
    pub next_voice_id:    VoiceId,
    pub pitchled_reasons:      PitchLedReasons,

    // Single source of truth: which chord buttons are *physically*
    // depressed right now, in press order. Updated on every chord
    // press/release event in both modes.
    //   Nursed mode: this IS the emit stack; top = current emitter.
    //   Toggle mode: informational; consulted on Toggle→Nursed flip.
    pub pressed_chords:   Vec<ChordId>,

    // Modal state for the set-accretion-target gesture.
    pub target_select_mode:  bool,

    // Buttons indexed by their cell. Both control windows pool
    // into the same map; dispatch is by Window.id but the lookup
    // is uniform.
    pub control_buttons:  HashMap<MonomeKey, Button>,

    // Immutable config:
    pub pitch_class:      PitchClass,
    pub fund:             f64,
    pub edo:              i32,
    pub sample_rate:      f32,
  }
#+end_src

* Brightness mapping

In =leds.rs=:

#+begin_src rust
  // The monome appears to render only 4 distinct brightness levels
  // across the 0..15 API range — buckets of 4. See README's "Coding
  // the monome" section. This function maps our exhaustive
  // Brightness enum to the OSC level int. Conjecture: index i =>
  // 4*i; verified by 12-brightness-test.sh in commit 2.
  pub fn low_res_brightness(b: Brightness) -> i32 {
    match b {
      Brightness::Off => 0,
      Brightness::B0  => 4,    // dimmest lit
      Brightness::B1  => 8,
      Brightness::B2  => 12,
      Brightness::B3  => 15,   // full
    }
  }
#+end_src

(If the brightness test reveals a different bucketing, only this
function changes.)

* Behavioural rules

** EDO press of cell C
1. Compute =P = pitch_class.key_to_pitch[C]=.
2. Generate =id = next_voice_id; next_voice_id += 1=.
3. Insert =Fingered{xy:C}= → fresh =VoiceState{ id, freq, phase=0,
   env=0, target_env=1.0, ramp_per_sample=1/(0.003·sr) }=.
4. *If* =accrete_on=:
   - Let =target = accretion_target=.
   - If P is *not yet* in =chords[target]=, insert
     =P → {id}=.
   - If =emitting_chord == Some(target)= (slot mutation while
     emitter is the same chord), add =PitchLedReason::Chord{chord:
     target, pitch: P}= for every cell in
     =pitchclass_to_keys[P mod edo]=. (LED diff via the compositor.)
5. For every cell C' in =cells_for_pitch_of(C)=, add
   =PitchLedReason::PitchEquivalent{source_xy: C}= to
   =pitchled_reasons[C']=. LED on for newly-lit cells.

** EDO release of cell C
1. Compute P. Look up the finger voice at =Fingered{xy:C}=.
2. For every cell C' in =cells_for_pitch_of(C)=, remove
   =PitchLedReason::PitchEquivalent{source_xy: C}=. LED off for
   newly-dark cells.
3. Decide voice fate:
   - Let =em = emitting_chord=. If =em == None= → ramp to 0.
   - Let =em = em.unwrap()=. If P is *not* in =chords[em]=
     → ramp to 0. (Per Round 1 answer: transform requires the
     pitch be in the *emitting* chord's slot, not just any
     chord's.)
   - If =Accreted{chord: em, pitch: P}= already exists in voices
     → ramp to 0.
   - If this voice's id is *not* in =chords[em][P]= (this
     voice wasn't an originVoice for em) → ramp to 0.
   - If any *other* alive (target_env > 0) voice's id is in
     =chords[em][P]= → ramp to 0 (not the last alive
     originVoice yet).
   - Else: *transform* — rekey the entry from =Fingered{xy:C}=
     to =Accreted{chord: em, pitch: P}=, set =target_env = 0.5=,
     =ramp_per_sample = |env − 0.5| / (0.05·sr)=.
4. "Ramp to 0" means =target_env = 0=,
   =ramp_per_sample = env / (0.05·sr)=.

** Chord-button press (cell (chord, 15) for chord ∈ 0..=15)
Behaviour depends on =emit_is_toggle= and on
=target_select_mode=.

*** If =target_select_mode=:
- If chord ∈ 1..=15: =accretion_target = chord=,
  =target_select_mode = false=. LED diffs: stop flashing
  =CELL_SET_ACCRETION_TARGET=, repaint old target dark, repaint
  new target dim.
- If chord == 0 (silence): exit the mode without changing target.
  Stop flashing. (Per "any chord-related button that's not a
  legitimate chord exits with no change".)

*** If not in target-select mode AND =emit_is_toggle=  (Toggle mode):
- If =emitting_chord == Some(chord)= → toggle off:
  =emitting_chord = None=. Ramp all =Accreted{chord: chord, ..}=
  voices to 0. Remove their =Accretion{chord, ..}= LED reasons.
- Else → switch emitter:
  - If =emitting_chord = Some(prev)=, prev ≠ chord: ramp prev's
    Accreted voices to 0; remove prev's Chord-variant LED reasons.
  - =emitting_chord = Some(chord)=. For each P in
    =chords[chord]=, spawn =Accreted{chord, pitch:P}= unless
    a live originVoice is held; add =Accretion{chord, pitch:P}=
    LED reasons.
  - Update =CELL_(prev,15)= LED → off (per chord LED rules).
    Update =CELL_(chord,15)= LED → full bright.
- Always update =pressed_chords= with this chord (push if not
  present, no-op if present — Toggle's "press and never release"
  doesn't track presses precisely, but the press *event* still
  pushes for the Toggle→Nursed-flip rule).

*** If not in target-select mode AND NOT =emit_is_toggle=  (Nursed mode):
- Push =chord= onto =pressed_chords=. (If already present, move
  it to the top — per Round 2 answer to case 5.)
- The new top of =pressed_chords= is the new emitter:
  - If =emitting_chord == Some(prev)=, prev ≠ chord: ramp prev's
    Accreted voices to 0; remove prev's Chord-variant LED reasons.
  - =emitting_chord = Some(chord)=. For each P in
    =chords[chord]=, spawn (with originVoice check); add
    Chord-variant LED reasons.
  - Repaint chord LEDs accordingly.

** Chord-button release (cell (chord, 15))
*** If =emit_is_toggle=  (Toggle mode):
- Remove =chord= from =pressed_chords= (if present). No emitter
  change. No LED change. (Toggle ignores release.)

*** If NOT =emit_is_toggle=  (Nursed mode):
- Remove =chord= from =pressed_chords= (anywhere it appears).
- If it was the top: ramp the now-old emitter's Accreted voices
  to 0; remove its Chord-variant LED reasons.
  - If =pressed_chords= is now non-empty: new top = new emitter;
    spawn Accreted voices and add Chord-variant LED reasons.
  - Else: =emitting_chord = None=. Repaint chord LEDs.
- If it wasn't the top: no audible/visible change beyond the
  internal stack update.

** =wipe= press (Fire)
- Let =target = accretion_target=.
- Clear =chords[target]=.
- If =emitting_chord == Some(target)=:
  - Ramp every =Accreted{chord: target, ..}= voice to 0.
  - Remove every =Accretion{chord: target, ..}= LED reason.
  - Repaint accordingly.
  - JEFF ADDs : also set emitting_chord = none.
- Else: no audible change. Visually: target stays dim (still the
  target, just empty).

** =accrete-on= press (Toggle)
*** Off → on
- =accrete_on = true=.
- Atomic per-pitch snapshot: group held finger voices by pitch,
  insert =P → { all held voice ids for P }= into
  =chords[accretion_target]= for any P not already present
  there.
- If =emitting_chord == Some(accretion_target)=, add Accretion
  LED reasons for any newly-introduced P.
- LED for =CELL_ACCRETE_ON= → full bright.

*** On → off
- =accrete_on = false=. =chords= unchanged. LED off.

** =emit-is-toggle= press (Toggle, default state = on)
On every press, flip =emit_is_toggle=. Then:

*** Toggle → Nursed
- The currently-emitting chord stays emitting *iff* it is in
  =pressed_chords= right now.
  - If yes: =pressed_chords= already contains it; that is the new
    emit stack.
  - If no: silence the current emitter (ramp its Accreted voices
    to 0; remove its Chord-variant LED reasons; =emitting_chord =
    None=; repaint).
- Repaint =CELL_EMIT_IS_TOGGLE= → off.

*** Nursed → Toggle
- Snapshot: the top of =pressed_chords= (if any) becomes the
  Toggle-on chord. =emitting_chord= already reflects this; no
  audible change.
- The chord button at (top, 15) gets its =Button::Toggle.state=
  set to =true=; all other chord buttons reset to false. (We
  rebuild the chord buttons on every mode flip anyway.)
- Repaint =CELL_EMIT_IS_TOGGLE= → full bright.

** =set-accretion-target= press (Fire)
- =target_select_mode = !target_select_mode=. (Pressing it again
  while already in the mode cancels it — per Round 2 answer:
  "any chord-related button that is not a legitimate chord exits
  it, with no change.")
- If now in mode: start flashing =CELL_SET_ACCRETION_TARGET= at
  the FLASH cadence (see Flash tick below).
- If exiting: stop flashing; restore the cell to its non-flash
  brightness (dim, level B0 — same as the accretion target).

** Other control button presses while in target-select mode
- =wipe=, =accrete-on=, =emit-is-toggle=: cancel target-select
  mode, then perform the button's normal action. (Per Round 2:
  these are "chord-related" in the sense that they belong to the
  chord-storage UI. Only EDO presses are exempt.)
- EDO key press: independent. Mode stays active. (Round 2 answer.)

** Flash tick (in main event loop, alongside heartbeat)
The main loop wakes every 50 ms. On each wake:
- If =target_select_mode= is true:
  - Compute =flash_phase = (start.elapsed().as_millis() /
    FLASH_PHASE_MS) % 2= (0 or 1).
  - If =flash_phase != last_flash_phase=, emit one LED-level cmd
    for =CELL_SET_ACCRETION_TARGET=:
    - phase 0 → =Brightness::B3= (full)
    - phase 1 → =Brightness::Off=
- If we just exited target-select mode, force one paint to
  restore the cell to =Brightness::B0= (dim).

** Mode flip implications for the chord buttons
On every =emit-is-toggle= press, walk =control_buttons[(c, 15)]=
for c in 1..=15 (and the silence button at (0,15)):
- Reset to =Button::Toggle{state, ..}= or =Button::Nursed{state,
  ..}= according to the new mode, with =state= set to:
  - Toggle: =true= iff =Some(c) == emitting_chord=, else =false=.
  - Nursed: =true= iff =c= is in =pressed_chords=, else =false=.

* LED model

*** Per-cell brightness

| MonomeKey                      | Brightness                                       |
|---------------------------+--------------------------------------------------|
| chord c (1..=15) at (c, 15) | =B3= if =Some(c) == emitting_chord=,           |

*** Repaint
The =repaint= helper (called at startup, after re-register on
serialosc port change, and on any state-changing event that may
have shifted multiple cells) walks the table above and pushes the
right brightness for every owned cell through the compositor.
