* Re-grounding vs 6_plan.org (important)
6_plan was written against =sawwave/= as "the synth". Reality on disk:
- The *looper is already built*: =looper_runtime/= (state/sink/loop_store/remap/
  display/mod, + a =mock_monome= test rig). So the looper-dependent commits
  (C5c/C6/C7) are *not* blocked on a future looper -- the pieces exist.
- The looper's =SawNoteSink= (=looper_runtime/sink.rs=) owns its own =VoiceMap=
  but *renders through the shared sawwave engine*: =voices::render_block_with_amplitude=
  + =types::VoiceState=. So C1/C2 (per-voice timbre + DSP) land in
  =sawwave/types.rs= + =sawwave/voices.rs= (shared by both runtimes) and
  =looper_runtime/sink.rs= -- exactly the files 6_plan named, just confirmed shared.
- Both the old =sawwave_runtime= and the looper render triangle via that engine and
  use the =cpal_sawwave= sink kind (configs: monome-edo-sawwave, monome-looper-58-8-1,
  -mock). So C0's rename touches config.rs + 3 toml + 2 runtimes.

* Plan adaptation (decisions, all reversible -- mine to make)
- *Commit order:* do the functional, well-grounded, fully-unit-testable synth work
  (C1, C2) FIRST; do C0 (cosmetic =cpal_sawwave=->=cpal_synth= rename) later as its
  own mechanical commit (or defer). Rationale: a cross-cutting rename has
  build-break risk and zero functional value; not worth front-loading in an
  unattended run. 6_plan's "each commit independent" allows the reorder.
- *Timbre data lives in =sawwave/types.rs=* (=Waveform=, =Am=, =Fm=, =Timbre=),
  embedded in =VoiceState= (+ runtime =am_phase=/=fm_phase=). The engine must see
  them to render; the looper imports them.
- *=note_on= takes an explicit =timbre: Timbre=* (not a stateful setter), so loop
  playback can pass each note's stored timbre in C6 without re-churn.
- *Same-pitch collision:* voices stay keyed by pitch (the existing ref-count
  model), so if two sources sound the *same* pitch at once with *different*
  timbres, the first holder's timbre wins (one shared voice). Different pitches --
  the common case -- are unaffected. Reversible (key by source+pitch later) if it
  ever matters; noted, not blocking.
- *Band-limited square/saw* via PolyBLEP (per 6_plan 2.5); sine/triangle naive.
