* DONE better FM
According to (someone?), "The most advanced linear synths use "Through-Zero FM." If the modulation forces the frequency below 0 Hz, the oscillator doesn't stop; it flips its phase (180°) and runs backward, exactly like a Ring Modulator (DSB-SC) does at the zero line."

I don't know whether we already do this. If not, let's,

** [Claude] answer: our FM can't reach 0 Hz -- but the oscillator core now handles it anyway
The only FM in this codebase is the per-voice vibrato in
=code/rust/midi_pulse/sawwave/voices.rs= (=fm_factor=), shared by all three
synth runtimes (sawwave, looper, surfaces). It is *exponential* FM: the depth
is in *cents*, so the carrier frequency is multiplied by =2^(depth*sin/1200)=,
which is always > 0. No depth can force the frequency below (or even to) 0 Hz,
so through-zero territory is *unreachable* -- it's a property of *linear* FM
(freq = carrier + deviation in Hz), which we don't have.

That said, the oscillator core is now genuinely through-zero-capable:
- the phase accumulator wraps with =rem_euclid=, so a negative increment runs
  the oscillator backward instead of walking the phase out of range -- for a
  sine that is exactly the 180° flip the quote describes (=sin(-x) = -sin(x)=,
  the ring-mod identity at the zero line);
- PolyBLEP band-limiting uses =|dt|=, so square/saw stay band-limited while
  running backward.
Unit tests pin both behaviors. If we ever add *linear* FM (or any modulator
that can push frequency negative), through-zero comes for free.

If what you actually want is audible through-zero *linear* FM as a playable
timbre dimension, that's a new timbre parameter + config surface -- happy to
build it, but since nothing existing would change sound, I stopped here.
(Also noted in jeff-maybe-review-this.org.)
* DONE sustain ("accrete")
For the 3-surfaces rig(s) -- that is, softstep + 2 monomes --
let's put three buttons in the bottom row on the left:
- clear : Silences and flushes all accreted notes. Lights when pressed. Works on key-down; does nothing on key up.
- accrete-needs-holding : Pressing this changes the way the third button behaves. Key down toggles state; key up does nothing. When accrete needs holding, this is lit; otherwise accrete does not need holding.
- accrete : If "accrete needs holding", then holding this key down causes any notes fingered on the big edo grid (even if they were pressed before this, as long as they are now held) to be added to the sustained set. The sustained set of notes will continue ringing even when they stop being fingered, until the sustained set is cleared. If accrete does not need holding, then key-down toggles 'accrete mode', where every note played (plus any that were being held when it entered accrete mode) becomes part of the sustained set. key-up does nothing. When accrete mode is un-toggled, new notes are not added to the sustained set, but nothing is deleted from the sustained set until 'clear' is pressed.

* slide
Let's introduce a janky slide algorithm.
Toggle it (key up does nothing) with the button
right next to the distortion button (so (1,1)).

Remember what notes have been played.
(Maybe something else already does.)
Each time a new note is played,
find all notes that were being held within the last
'slide-candidate-window' miliseconds but released before it.
The nearest should be re-triggered,
and should slide into the new pitch,
taking 'slide-duration' miliseconds to reach it.

When that happens, the source pitch
(the early one, sliding into the target, which comes later)
is removed from the candidate set for any further notes
that might be triggered in the future.
