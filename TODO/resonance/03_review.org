Commit e6460d5: junction, body bank, string voice, renderer,

**** Decision: the bridge is lossy, default heaviness 3000
At r = 50 a 110 Hz note hit -40 dB in 0.43 s against a 6.8 s
T60 curve. That is what a resistive bridge does; compensating
the loss filter would make the anti-phase modes exceed unity.
Default 3000 keeps the bridge's own T60 above the curve's
except near the top, and the rig will document the trade.
**** Decision: no reaping of silent strings
Slice 3 reaped silent string voices after a second and did not
respawn them, which removed sustained drones from the junction.
A drone is the string Jeff wants excited in sympathy, and a
loop is cheap, so slice 4 removes the reaper.
**** Accepted deviations
No respawn (moot once reaping goes), the re-strike scene cuts
the drone the way 'cut_sustained' does, a changed unison count
applies to later notes, voices live in a 'BTreeMap' so the
junction sums in a fixed order.

** Suggestions for the advice
*** A plan's numbers need a render before the run
Every default and formula the plan stated from the literature
without rendering it moved during the run. 'plans.org' says to
read the code path before stating a rule about existing
behavior; the analogue for DSP is to render the formula before
stating a default. A first slice that is only a numeric harness
(slice 3's, moved first) would have let the planner tune the
numbers before writing them into eight slices.
