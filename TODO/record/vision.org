* the idea in brief
I would like to implement some new features
for the edo-un12*.toml family of rigs at rigs/.
(Each of those represents a slight variation on, essentially, the same program.)

I would like some controls on the monome for recording from the piano.
They should permit recording and playing-back of
the whole finger-to-ear signal chain:
- the 12-edo pitch
- the mapped-to higher-edo pitch
- note on, note off, velocity
* controls
** where
Let's put them in the top-right, in a 2x3 grid:

arm    block ons   end all
start  stop        loop

** arm recording
Can be done during playback, which triggers overdub.
** start playback
and recording if armed.
** TODO stop recording
without triggering playback.
Resets playhead to 0.
** loop and unarm recording
while recording, this sets the playhead to zero,
effectively triggering playback,
and discontinues recording.
** silence note-ons
While held during recording,
this erases any note-ons that had been recorded.
This is the only one of the six controls
for which key-up does anything.
** end all notes
When pressed during recording,
this writes a note-off to the recording for each note currently on.
It also deletes the later note-off corresponding to that note-on.
* nuances
** playback before recording
If the recording slot is empty --
not just devoid of note ons,
but devoid of the very time duration they would occupy --
then pressing 'start playback' does nothing.
** What is overdub?
Let's treat each note on the keyboard as something that
can either be down or up at one time.
A note-on overdubbed onto a note already playing in the recording
should be preceded by 10 ms by a note-up.
If somehow a new note-on is played at exactly the same moment
as a recorded one, the new one clobbers it.
In fact even if the old one follows it,
as long as it follows by less than 50 ms,
the new one clobbers the old one -- the old one is removed.
