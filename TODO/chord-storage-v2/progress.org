* DONE 9. correction: the base cycle (queues/branch-2.org)
Jeff corrected the phase scheme post-landing: "longest phase -> longest
period". =snapshot= now anchors on the LONGEST-PERIOD (lowest-pitch) voice
and REWINDS the save instant to the start of that base cycle (=dt =
phase_B / freq_B=), storing every oscillator phase -- and every pulse phase,
same =dt=, one coherent instant -- as of then. The base stores exactly 0
(special-cased so float rounding cannot wrap it to ~1); frequencies derive
from the stored pitches (what a recall replays), not mid-glide live freqs;
the separate pulse-reference fallback rule is gone. Second refinement (chat):
ties between co-pitched base candidates go to the voice closest to its cycle
boundary in either direction, and the anchor is the base's NEAREST boundary
-- =dt= is signed, so a base past half-cycle ADVANCES to the start just
ahead rather than rewinding almost a full cycle. Old state files reload
fine (same fields, phases are phases) but were written under the old
anchoring; resave to re-anchor. Tests rewritten around an exact-octave pair.

* what's imperfect about what's done
- The timbre crossfade renders the OLD timbre's modulators off the voice's
  shared LFO phases (advanced at the new timbre's rates) for the fade's
  ~50 ms -- documented at =TimbreXfade=; inaudible in practice, but not
  sample-exact.
- =1 cycling ON while a chord voice is edited SETS its pulse rate (like any
  edited note), which can start a pulse on a chord voice that was saved
  without one -- consistent with the =1 rules for piano-layer notes, but
  worth knowing next to "a recall cannot start a pulse".
- Stopping cycling via =1 still steps an edited voice's pulse amplitude to 1
  (the pre-existing accepted click), chord voices included.
- The chord block's save writes the whole state file on the grid thread
  (~a ms of file I/O on a save gesture); fine in practice, noted for honesty.

* choices determining the future
- Chord voices are per-VOICE state everywhere (registry + flags), so a future
  "select one of two chord voices at a pitch" gesture has somewhere to stand.
- The persistence file is versioned (=version = 1=) and keyed by monome id,
  so both schema evolution and monome renames have clean paths.
- =drive_accrete= is now the single clear implementation for hands and feet;
  future accrete-control changes should land there once.
