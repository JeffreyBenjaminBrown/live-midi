Choices where the spec was loose -- none seemed worth stopping for, but read
the first two, they change behavior you already had:
- *Accrete-editmode is a ONE-SHOT, not a momentary hold.* The sustain accrete
  can capture "notes played while held" because notes still play while it is
  live. Edit mode can't: the moment ANY note is edited, the grid becomes a
  pitch-picker (every press drags instead of playing), so a hold-to-add phase
  has nothing to add. Key-down captures everything sounding at that moment.
- *The clears are now symmetric, which CHANGES the sustain clear.* Each clear
  removes only its own reason: sustain-clear no longer empties edit mode (the
  old panic-button coupling), and editmode-clear does not touch the sustain
  bank. A note both sustained and edited survives either clear alone --
  audibly, so the old silent "dancing ghost" cannot recur -- and dies to the
  two clears together. This also replaces yesterday's edit-delete semantics
  (which un-sustained as a side effect); the (12,0) button is now the
  editmode clear.
- *Capture happens at the stomp.* Both accretes capture what is fingered /
  sustained / edited AT that moment (sustain-accrete additionally keeps
  capturing notes fingered while held, as before). A note that enters edit
  mode DURING a live sustain-accrete hold does not auto-join the bank, nor
  vice versa; stomp again if you want it.
- *Naming:* the rig kinds are =editmode_control= with =control = "clear" |
  "accrete"= (pedal and on-grid forms), mirroring =accrete_control=;
  yesterday's =edit_delete_*= kinds are gone. The erase pedal (unbound in
  this rig) still erases fingered notes only -- extending it to edited ones
  seemed out of scope; say the word.
