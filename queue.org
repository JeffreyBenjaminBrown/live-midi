** DONE the aggressive debounce for the timing pedals
The decoder now has a per-pad debounce mode. The timing pedals (=x2=, =x3=,
=/2=, =/3=) use a new =Settle= mode. A pad fires once, emits no amplitude revise,
and then accepts no further fire until two conditions both hold. The first
condition is that at least =factor_settle_ms= (150) has passed since the fire.
The second condition is that the pad has been inactive, meaning its sum-of-4 has
stayed below the release threshold, for at least =factor_release_ms= (25). A
bouncing single stomp keeps re-crossing the release threshold, which restarts the
inactivity clock, so the second condition is never met mid-stomp and one stomp is
exactly one event. After a long hold the pad re-arms about 25 ms after the foot
lifts rather than 150 ms later, so quick repeats stay responsive. This replaced an
earlier steady-for-150-ms rule, per your note in =hey-jeff.org=.

Everything else (drum pads, the accrete pedals) keeps the old =Standard= mode.

** DONE the 25 ms stuck-sensor rule already holds
The de-stick (=silence_to_zero_ms=) is already 25 ms for every pad, so a sensor
with no reading for 25 ms already reads zero. Nothing to change there.
