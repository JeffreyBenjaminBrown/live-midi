*** DONE claude: the base cycle, one rewind for everything
=chords::snapshot= now picks the LONGEST-PERIOD voice (lowest pitch; ties to
the largest phase) as the base and rewinds the save instant by =dt =
phase_B / freq_B= seconds -- to the most recent start of the base's cycle.
Each voice stores its phase as of that instant (=phase_i - dt * freq_i=, from
the stored pitch's frequency, so a mid-glide save uses the target it will
replay at), which is one number that encodes both "where it was in itself"
and "where it was relative to the base cycle"; the base stores exactly 0.
The factored-pulse phases rewind by the SAME =dt= (one coherent instant),
which also removed the old separate pulse-reference rule. Docs updated
(2_discussion Round 3 note, both readmes, StoredVoice/snapshot comments);
tests rewritten around the octave-pair rewind math. =cargo test
