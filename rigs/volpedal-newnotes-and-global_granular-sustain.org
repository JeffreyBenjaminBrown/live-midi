Run from the repository root:
=pw-jack cargo run --bin midi_pulse -- volpedal-newnotes-and-global_granular-sustain=
Derived from [[file:monomes_two-timbres_sustain_chords.org]]: the same grids,
tuning, sound, timbres and volume keys, minus chords, loops and the tone target,
plus two EX-P pedals -- one setting each new note's starting volume, one a live
global volume over every note -- which each monome opts into with its own two
buttons, a per-note sustain handle one cell below each sounding note, and three
sustain buttons. Hence the name: a new-notes pedal and a global pedal, and
sustain note by note.

*** some favorite tunings
**** 41 8 1, 41 13 -2
**** 27 9 1, 27 9 2
**** 58 8 1
*** PARAM id = "main"
*** PARAM edo = 41
*** PARAM x_step = 8
*** PARAM y_step = 1
*** PARAM fundamental_hz = 110
Pitch rises by 8 EDO steps to the right and 1 step downward. Pitch 0 is 110 Hz.
So the sustain handle (the cell directly below a note) is also the cell one EDO
step above it.

**** PARAM sample_rate = 48000
**** PARAM buffer_frames = 128
**** PARAM amplitude = 0.15
**** PARAM attack_secs = 0.003
**** PARAM release_secs = 0.050
**** PARAM sustain_level = 0.35
**** PARAM decay_secs = 0.5
**** PARAM crowded_pitch_planck_deviation = 5
Equal-nominal-pitch surface voices take the first free lane in
=0,+p,-p,+2p,-2p,...=, where this parameter is =p= in cents.  Set it to zero to
disable crowded-pitch separation.
** the EX-P volume pedals
Both reach the runtime through the MPC-20 -> host bridge: run
=tools/pedals/bridge.sh= on the HOST before starting the rig, which looks for the
"MPC-20 pedals" port only at startup (without it, a red note, and no pedals).
A note's volume at any moment is its START level times the GLOBAL level (times the
volume keys and the rest), each pedal running heel = silent to toe = unity on the
fader-law taper. Channel 1 (=new_note_volume=) sets the level each note starts
at, kept for its life; moving it never changes a note already sounding. Channel 2
(=global_volume=) is a live level over every note, held or sustained. Each pedal reaches every grid (no =monome=), and each grid opts in or out of each
with its two =pedal_toggle= buttons (bottom-left; lit = listening). Until a pedal
first moves it counts as unity, so an unplugged pedal mutes nothing. Swap the
=channel= values if the pedals are cabled the other way round.

** grid A: the first available 16x16 monome
*** ELEM monomes
**** PARAM id = "a"
**** PARAM listen_port = 9000
**** PARAM prefix = "/volpedal-a"
**** PARAM select.size = [16, 16]
No serial pin: whichever matching monome serialosc reports first may fill A.
*** ELEM monome_windows
**** PARAM id = "grid-a"
**** PARAM monome = "a"
**** PARAM kind = "edo_note_grid"
**** PARAM rect = [0, 0, 15, 15]
**** PARAM tuning = "main"
**** PARAM sink = "synth"
**** PARAM sustain_handle = "below"
**** PARAM edit_handle = "none"
**** PARAM flash_sustained = true
Press the cell directly below a sounding note to toggle that note's sustain;
the press never sounds. "above", "left" and "right" also work. There is no
edit mode here, so the edit handle is off. Sustained notes no finger holds
flash bright on the same 150 ms clock as the resting controls' dim flash; held
notes stay steady.

*** ELEM monome_windows

**** PARAM monome = "a"
**** PARAM kind = "accrete_control"
**** PARAM rect = [7, 15, 7, 15]
**** PARAM control = "accrete"
ON: notes held now, and notes played while it is on, join the sustained set.
*** ELEM monome_windows
**** PARAM id = "sustain-mode-a"
**** PARAM monome = "a"
**** PARAM kind = "accrete_control"
**** PARAM rect = [8, 15, 8, 15]
**** PARAM control = "needs_holding"
**** PARAM initially_on = true
TOGGLE WHAT ON MEANS: bright = ON is momentary (hold it), dim = ON latches
(tap it on, tap it off). Starts bright.
*** ELEM monome_windows
**** PARAM id = "shift-a"
**** PARAM monome = "a"
**** PARAM kind = "edo_shift_pad"
**** PARAM rect = [13, 0, 15, 1]
*** ELEM monome_windows
**** PARAM id = "new-note-pedal-a"
**** PARAM monome = "a"
**** PARAM kind = "pedal_toggle"
**** PARAM rect = [0, 15, 0, 15]
**** PARAM role = "new_note_volume"
Lit: notes struck on this grid start at the new-note pedal's level. Dim: they
start at unity. Either way nothing already sounding changes.
*** ELEM monome_windows
**** PARAM id = "global-pedal-a"
**** PARAM monome = "a"
**** PARAM kind = "pedal_toggle"
**** PARAM rect = [1, 15, 1, 15]
**** PARAM role = "global_volume"
Lit: every note on this grid rides the global pedal. Dim: they sit at unity
(gliding there). Both buttons start lit; add =initially_on = false= to change that.
