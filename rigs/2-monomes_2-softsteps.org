* 2-monomes_2-softsteps
** about
This rig is written in a TOML-in-org format unique (so far) to this repo.
The data lives in headlines titled
"PARAM key = value" (values are ordinary TOML syntax); "TABLE name" / "ELEM name"
headlines nest tables and array-of-table elements; any other headline just groups and
documents; and every body (like this one) is a human note the loader ignores. A "#" on
a headline starts a comment, TOML-style, even on a load-bearing one. Format reference
(C-c C-o to follow): [[file:README.org]]
Reference doc for this rig: [[file:2-monomes_2-softsteps_readme.org]]

*** PARAM version = 1

*** PARAM id = "2-monomes_2-softsteps"
*** PARAM title = "Two monomes + two SoftSteps"
** shared SoftStep parameters (softstep.toml)
This rig drives at least one SoftStep board. Every board reads its detection and
pressure parameters from the shared file rigs/softstep.toml, not from this rig
file. That shared file holds the onset and release thresholds, the attack window,
the pressure scaling, the contact-bounce and settle debounce guards, and the
de-stick window. Every rig that uses a SoftStep reads the same file, and the
meter reads it too, so one edit there reaches all of them at once.
** TABLE surfaces # TODO : this is a dumb name for a diverse collection
===========================================================================
FOUR SURFACES, NO DRUMS. Two 16x16 monome grids, each a full 46-EDO play
surface, and two SoftStep boards that carry the controls that would
otherwise cost grid cells: sustain and the factored pulse.
Each grid keeps three overlays -- a 4-cell waveform strip (top-left), a 3x2
factored-pulse pad (top-right, doubling the NSS pedals), and a 3x2 scroll
pad (bottom-right). Everything else on the grid is a note.
Launch under pw-jack so the synth shares the card via PipeWire:
pw-jack cargo run --bin midi_pulse -- 2-monomes_2-softsteps

Shared recent-note trail (the dim backdrop of the last few played pitch classes).
*** PARAM trail_clobber_radius = 27
Clobber radius as a divisor of the octave: a played note clears any trailed class
within edo/trail_clobber_radius steps of it. 27 -> 1/27 of an octave (~44 cents).
*** PARAM trails_max = 9
At most this many distinct pitch classes in the trail (newest first).
*** PARAM slide_candidate_window_ms = 1000
Slide: a released note stays a slide source for this long.
*** PARAM slide_duration_ms = 100
How long a glide takes. ALSO the per-voice pitch-edit drag time: dragging an
edit-mode note to a new pitch reuses this, so 'r' retunes the drag feel live.
Jeff's starting value; slow enough to hear it move, fast enough not to smear
the rhythm.
*** PARAM tap_tempo_window_ms = 2000
Two taps at most this far apart on a pad's tap cell set the one global tempo.
The base is seeded at 1 Hz, so tapping is optional: the tap pedal was retired
(Jeff never tapped), and the on-grid pads' tap cells are the only tap source.

*** PARAM x_step = 9

"one microtone above" a note is the cell directly BELOW it -- which is what the

** the two monomes
Pinned by SERIAL, not by size. Every softstep pedal below targets a monome BY
NAME ("clear the left monome"), and Jeff's whole layout is spatial -- left
buttons drive the left grid. Assign by enumeration order instead and a replug
silently swaps the grids, inverting the entire pedal board with no error.
Get the serials with: send /serialosc/list to 127.0.0.1:12002.

** the two softsteps
Distinguished by ALSA client name, which is reliable: the older board presents
as "SSCOM", the newer as "SoftStep". Their CARD numbers follow plug order and
are NOT stable, so nothing here names one.
*** old softstep: sustain
Sustain is momentary only: hold to accrete, release to stop. Two controls per
grid (clear + accrete) rather than the on-grid four -- needs_holding and erase
stay in the library, just unbound here. The tap pedal that once sat here was
retired; the base tempo is now a fixed 1 Hz.
Left buttons drive the left grid, right buttons the right grid.

# The tap-tempo pedal was retired: Jeff never used it to set a tempo. With no tap
# source, the runtime fixes the base tempo at 1 Hz (see rig_has_tap_source /
# PolyrhythmState::set_fixed_tempo), so the x2 / /2 / ... pedals still have a base to
# multiply. Pedals 3, 6, 7, 8, 9, 0 on this board are now free.
*** new softstep: the factored pulse, 5 controls per grid
Each grid gets x2, x3, /2, /3 and =1. The far/near split follows Jeff's rule for
the ambiguous middle column: nearer = left grid, farther = right grid.
What a multiplier acts on depends on that grid's edit state -- with no note in
edit mode it moves the GRID's factor; with notes in edit mode it retunes THOSE
NOTES. =1 never retunes edit-mode notes; only the multipliers do.
