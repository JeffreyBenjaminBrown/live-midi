This rig is written in a TOML-in-org format unique (so far) to this repo.
The data lives in headlines titled
"PARAM key = value" (values are ordinary TOML syntax); "TABLE name" / "ELEM name"
headlines nest tables and array-of-table elements; any other headline just groups and
documents; and every body (like this one) is a human note the loader ignores. A "#" on
a headline starts a comment, TOML-style, even on a load-bearing one. It loads into the
exact same rig as the old .toml did. Format reference (C-c C-o to follow):

** shared SoftStep parameters (softstep.toml)
This rig drives at least one SoftStep board. Every board reads its detection and
pressure parameters from the shared file rigs/softstep.toml, not from this rig
file. That shared file holds the onset and release thresholds, the attack window,
the pressure scaling, the contact-bounce and settle debounce guards, and the
de-stick window. Every rig that uses a SoftStep reads the same file, and the
meter reads it too, so one edit there reaches all of them at once.
** about the rig
===========================================================================
THREE SURFACES AT ONCE (see rigs/2-monomes_kmss-drums.org):
- two 16x16 monome grids, each a full 46-EDO play surface with its own
independent scroll register and its own voices;
- the KMSS pedalboard as a velocity-sensitive TR-808 drumkit.
Each grid also carries a 4-cell waveform strip on its top row that sets its
OWN timbre, a volume fader that sets its OWN loudness, and a 3x2 scroll pad
in the bottom-right that moves *that* grid's pitch window. The same pitch
fingered on both grids is two independent voices (releasing one never cuts
the other), each in its grid's currently-selected waveform.
Launch under pw-jack so the synth + drum sampler share the card via PipeWire:
pw-jack cargo run --bin midi_pulse -- 2-monomes_kmss-drums
===========================================================================
** TABLE trail
Shared recent-note trail (the dim backdrop of the last few played pitch classes).
*** PARAM clobber_radius = 27
Clobber radius as a divisor of the octave: a played note clears any trailed class
within edo/clobber_radius steps of it. 27 -> 1/27 of an octave (~44 cents);
bigger = tighter = fewer potential neighbors to clobber.
*** PARAM max = 9
How many distinct pitch classes the trail keeps at once (newest first).
** TABLE slide
Timing knobs for the slide_toggle windows.
*** PARAM candidate_window_ms = 1000
A new note may glide from a note released within this many ms...
*** PARAM duration_ms = 100
...taking this long to arrive at the new pitch.
** TABLE tap_tempo
Pairing window for the tap_tempo_pad.
*** PARAM window_ms = 2000
Two taps at most this far apart set the tempo.

** ELEM sinks
The play-grid synth (both grids' voices go here; each voice carries its grid's
waveform). Waveform-only timbre -- gain/AM/FM stay at their inert defaults.
*** PARAM id = "synth"
*** PARAM kind = "cpal_synth"
*** PARAM sample_rate = 48000
*** PARAM buffer_frames = 128
*** PARAM amplitude = 0.15
The single master synth volume for BOTH grids (linear; 1.0 = full scale). Pull the
synth down here if it clips. The on-grid volume faders are live per-grid trims that
multiply *below* this.
*** PARAM attack_secs = 0.003
*** PARAM release_secs = 0.050
*** PARAM sustain_level = 0.35
Pluck envelope: a fresh strike peaks, then decays exponentially toward
sustain_level x peak (time constant decay_secs), so new notes ring out over held
ones -- a rough plucked-string curve that plateaus instead of dying (held notes
and accrete drones keep ringing at the sustain).
sustain_level: fraction of the strike peak; 0.2..0.5 natural, >= 1.0 disables.
An accreted note is the held voice itself, re-keyed, so it rings at this same
sustain: there is no separate accretion level.
*** PARAM decay_secs = 0.5
decay_secs: the decay time constant; ~0.3 snappy, ~1.5 slow ring, <= 0 disables.
*** PARAM distortion_scale = 0.01
Distortion (per-monome; heard only while a grid's distortion_toggle is on): the
soft-clipper f(y) = y / (1 + |y/s|^k)^(1/k) on the switched-on grids' summed mix.
scale s: the asymptote; ~0.3 heavy, ~1.0 strong, 2-3 gentle, >=5 nearly clean.
At 0.01 with the shape below, the mix sits far past the elbow -- a near-square
fuzz that loses ~19..31 dB, all of which distortion_auto_makeup gives back.
*** PARAM distortion_shape = 8
shape k: elbow harshness; 1 gentlest, 2 smooth sweet spot, 4-8 hard-ish edge.
Below 1 the curve bends straight from the origin and eats level fast -- k = 0.5
costs ~5 dB on a single note and ~9 dB on sixteen, before compensation.
*** PARAM distortion_makeup = 1.0
Loudness compensation, so the toggle changes timbre and not volume. 1.0 restores
the clean bus's RMS exactly. Equal RMS is not equal *loudness* (the distorted
signal is brighter, so it reads louder), so pull this toward ~0.8 if the
compensated sound feels hot. With distortion_auto_makeup off, this IS the makeup:
a plain constant gain on the distorted bus. Must be > 0.
*** PARAM distortion_auto_makeup = true
Track the makeup to the summed dirty bus's level, so note count changes loudness
exactly as much as it does with distortion off. Computed from the voice envelopes
(not an audio detector), so it neither lags nor pumps. Correct for every scale and
shape you can dial, not just the defaults. Set false for the old uncompensated
clipper. See learnings/distortion-volume-compensation.org.
*** PARAM distortion_makeup_slew_ms = 0.0
Lag the applied makeup behind its target, in ms. 0 (default) is exact, and preserves
attacks exactly -- it reproduces the clean bus's own envelope. Nonzero does NOT
protect attacks; it does the opposite. The makeup must RISE at a strike (a louder bus
loses more to the clipper), so lagging it under-corrects precisely where the clipper
bites hardest: 200 ms costs ~4 dB of attack contrast and adds a swell after the
strike. What nonzero buys is the clipper's own dynamic compression -- as this grows
the makeup freezes toward a constant, i.e. distortion_auto_makeup = false. A
character knob, not a fix. Try 0 first.

** ELEM monome_windows              # grid A accrete: clear
The sustain ("accrete") buttons, bottom row left. One accrete BANK per monome:
this trio drives only this grid's bank, and only notes fingered on this grid can
join it (see TODO/misc.org "sustain (accrete)"):
(0,15) clear         -- silence + flush this grid's sustained notes (lit while pressed)
(1,15) needs_holding -- toggles whether accrete must be held (lit when on)

they ring until cleared
(1,14) erase         -- accrete's mirror image (same needs_holding rule): pressed
pitches LEAVE the sustained set, each sounding until its
own finger lifts; when both are live, erase wins

** ELEM monome_windows              # grid A: polyrhythm pad
The polyrhythm pad, top-right: | x3 x2 tap | /3 /2 =1 |. Tap twice within
[tap_tempo].window_ms to set the tempo (the tap cell blinks at 10% duty,
at the UNFACTORED tapped tempo); the factor buttons scale it exactly (2^a * 3^b).
=1 starts this grid's cycling (keeping the factor), snaps to unity on a second
press, and stops on a fast double-tap. Notes struck while a tempo is applied and
cycling is on pulse with a unipolar triangle at that tempo (fixed per note,
separate from any [[timbres]] AM).
*** PARAM id = "poly-a"
*** PARAM monome = "a"
*** PARAM kind = "tap_tempo_pad"
*** PARAM rect = [13, 0, 15, 1]

*** PARAM id = "kit"
*** PARAM softstep = "feet"
*** PARAM kind = "drumkit"
*** PARAM sink = "drums"
*** PARAM pads = [ { pedal = 1, sample = "snare.wav" }, { pedal = 2, sample = "kick.wav" }, { pedal = 3, ditto = true }, { pedal = 4, sample = "hat.wav" }, { pedal = 5, sample = "open_hat.wav" }, { pedal = 6, sample = "high_tom.wav" }, { pedal = 7, sample = "low_tom.wav" }, { pedal = 8, sample = "wood_block.wav" }, { pedal = 9, sample = "cowbell.wav" }, { pedal = 0, sample = "crash_electronic.wav", gain = 0.5 }, ]
Detection/velocity knobs (debounce, de-stick, thresholds) are shared -- see softstep.toml.
Pedal 3 sits in the gap between the feet -- either foot can reach it. It
retriggers the most recently played sample on ANY pedal in this window, using
THIS press's own velocity against that sample's own pad's static gain trim
("a generalized double-bass pedal"); a ditto press does not itself become "the
last hit" (pad, ditto, ditto repeats the same sample, it does not echo the
ditto). Does nothing if nothing has played yet. See drumkit_runtime/mod.rs
(`PadKind::Ditto`).
